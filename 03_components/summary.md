## 本章小结

本章的组件都挂在同一条残差流上，下面每条规律给出一个判断和它的量级。

**分词决定序列长度，词表大小是三方取舍。** 词表矩阵的成本随模型变大而消失（同一张 128,256 行的表，在 Llama 3 8B 上占 13.1%，在 405B 上占 1.0%）；更大的词表让序列变短（Llama 3 扩到 12.8 万后英文序列缩短约 20%）；上限来自长尾词元的样本数，这是词表停在十万到二十几万的原因。数字切分、尾随空格、故障词元与多语言词元税都出在分词器与权重的接缝上（[3.1 节](3.1_tokenization.md)）。

**词表占比约为 $$kV / (kV + 12Ld)$$。** 层内参数随 $$d^2$$ 增长，词表只随 $$d$$ 增长，占比随规模单调下降：GPT-2 small 31.0%，Llama 3 405B 1.0%。占比高就绑定输入输出，占比低就放开（[3.2 节](3.2_embedding.md)、[3.7.6 节](3.7_full_architecture.md)）。

**无掩码的注意力看不出顺序，因果掩码可以。** 显式位置编码对解码器提供的是归纳偏置（相对位移），并非不可或缺；相加而不拼接，是因为拼接让每层参数按 $$d^2$$ 增长（[3.3 节](3.3_position_encoding.md)）。

**前馈网络是参数与 Decode 访存的主体。** 4 倍宽两矩阵时占一层三分之二，Llama 3 8B 配 GQA 后到八成；GLU Variants 的等参对照里 5 个门控变体全部优于 3 个不门控变体，起作用的是两路投影相乘（[3.4 节](3.4_feedforward.md)）。

**残差让网络像许多浅路径的集成，但不保证梯度不消失。** 恒等项提供直接通路，其他项可以与它抵消；前向看，末层表示等于嵌入加全部子层输出之和，方差随深度线性增长，均方根范数按 $$\sqrt{2L}$$ 增长，96 层时约为初值的 14 倍（[3.5 节](3.5_residual.md)）。

**归一化管读出的尺度，放在哪里比用哪一种更要紧。** Post-Norm 的恒等路径穿过归一化，层数多了离不开预热；Pre-Norm 保住纯加法通路，代价是残差流本身不受约束、末端要补一次归一化。RMSNorm 省掉减均值，质量相当而更简单（[3.6 节](3.6_layer_norm.md)）。

**$$12Ld^2$$ 是量级工具，$$T = 12d$$ 是两项相等的点。** $$12Ld^2$$ 在 Llama 3 8B 上低估约两成，在 405B 上吻合是抵消的结果；训练约 $$6ND$$、推理每词元约 $$2N$$；$$d = 4096$$ 时 8K 上下文的注意力项已占一层计算量的 14%（[3.7.7 节](3.7_full_architecture.md)）。

**Decode 的算术强度约等于读一遍权重服务的行数。** FP16 下单请求 Decode 约为 1，与模型大小无关；Prefill 约为 T，批量 Decode 约为 B，直到“批大小 × 上下文 × 每词元 KV 字节”接近权重字节（Llama 3 8B 约 12.3 万个词元位）后 KV 读取主导。KV 缓存与一次前向完成的教师强制训练靠的是同一条前缀不变性（[3.8 节](3.8_gpt_inference_flow.md)）。

**今天默认怎么做。** 一个公开权重的仅解码器层是：多为字节级 BPE 分词，词表十万到二十几万；嵌入一般不缩放，大模型不绑定输入输出；每层注意力内部用 RoPE；GQA，8 个左右的 K/V 头，每头宽多为 128；无偏置的 SwiGLU，中间宽度按参数预算定，常见为 $$d$$ 的 2.6 到 5.3 倍，个别达 8 倍；Pre-Norm 加 RMSNorm，归一化用 FP32 计算，末端再加一次。拿到一个新模型，先读 `config.json` 的七个字段，逐项算出参数、每词元 KV 字节和每词元运算量，再判断它在目标硬件上受算力还是受带宽限制。

本章留下一个问题交给[第四章](../04_position_encoding/README.md)：[3.3.4 节](3.3_position_encoding.md)只给出了正弦公式，并提到 $$\text{PE}(pos + k)$$ 可以写成 $$\text{PE}(pos)$$ 的线性函数，但没有说明为什么选用正弦，也没有说明这条线性性质为何成立。

### 自测

读完本章，应能不看正文回答下面几个问题；答不上来时，括号里是回看的位置。计算题的结果一并给出，供核对。

1. 用 3.1.2 学到的合并表 `(e, s)`、`(es, t)`、`(est, </w>)` 切 `west`，得到哪几个词元？编码时为什么按 rank 合并，而不是在词表里找最长匹配？（[3.1.3 节](3.1_tokenization.md)；结果是 `w` 与 `est</w>` 两个词元）
2. 一个模型的 `V = 32,000`、`d = 4,096`、`L = 32`，输入与输出不绑定。用 `kV / (kV + 12Ld)` 估算词表矩阵占总参数的比例。同一张词表放到更宽更深的模型上，占比为什么必然下降？（[3.2.4 节](3.2_embedding.md)；约 3.9%）
3. 无掩码的自注意力为什么看不出输入的顺序？加上因果掩码后，同样不加位置编码，为什么就能区分顺序？（[3.3.1 与 3.3.2 节](3.3_position_encoding.md)）
4. 沿用 3.4.1 手算例的 $$W_1$$、$$W_2$$，对 `x = [2, 1]` 算出两矩阵 FFN 的输出；再把输入取反算一次，说明输出为什么没有跟着取反。（[3.4.1 节](3.4_feedforward.md)；`[4, 3]` 与 `[−1, 1]`）
5. 残差连接把反向的连乘展开成 $$2^L$$ 条路径，其中的恒等项为什么不能保证梯度不消失？举一个反例。再按 3.5.4 的假设取 $$\text{Var}(h_0) = s^2 = 1$$，$$L = 24$$ 时残差流的均方根范数约为初值的几倍？（[3.5.3 与 3.5.4 节](3.5_residual.md)；7 倍）
6. 对 `x = [0, 0, 3, 4]` 算 RMSNorm 的输出及其 L2 范数，并用这组数验证 $$\text{RMS}^2 = \sigma^2 + \mu^2$$。Pre-Norm 结构为什么必须在模型末端再补一次归一化？（[3.6.3 与 3.6.5 节](3.6_layer_norm.md)；输出 `[0, 0, 1.2, 1.6]`，范数 2，`6.25 = 3.1875 + 1.75²`）
7. 一个 Llama 式模型的 `L = 32`、`d = 4,096`、`n_h = 32`。`n_kv` 从 8 降到 4，BF16 下每词元的 KV 缓存从多少降到多少？$$W_K$$、$$W_V$$ 的形状怎样变？（[3.7.5 节](3.7_full_architecture.md)；128 KiB 降到 64 KiB）
8. `12Ld²` 用在 Llama 3 8B 上低估近两成，用在 405B 上却几乎吻合，原因各是什么？`d = 4,096`、`T = 24,576` 时，注意力项占一层计算量的多少？（[3.7.7 节](3.7_full_architecture.md)；三分之一）
9. 权重按 FP16 存放时，为什么单请求 Decode 的算术强度约为 1，与模型大小无关？把 32 个请求合成一批，GPT-3 Small 在上下文 1,000 时为什么只升到约 6？（[3.8.8 节](3.8_gpt_inference_flow.md)；KV 读取约 1.2 GB，是权重 250 MB 的近 5 倍）

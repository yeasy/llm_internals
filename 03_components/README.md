# 第三章：Transformer 核心组件解析

本章的主线是一条**残差流**：宽度为 $d_{\text{model}}$ 的向量通路贯穿全模型，每个组件只是在这条通路上读或写。分词和嵌入把文本写进通路，词表矩阵在末端把它读出来打分；注意力在位置之间搬运信息，前馈网络就地算出新特征，两者都把结果加回通路；归一化管每个子层读到的尺度，初始化管写入的初始尺度。读懂这张图，一个模型的参数、算力与 KV 缓存都能凭 `config.json` 的七个字段算出来。

- [3.1 节](3.1_tokenization.md)：分词决定序列长度 $n$，它同时是算力、上下文与计费的单位。今天的默认是字节级 BPE、十万到二十几万的词表；词表的上限来自长尾词元的样本数。
- [3.2 节](3.2_embedding.md)：嵌入矩阵是读写通路的接口，参数 $V \times d$ 与层数无关，占比约为 $kV / (kV + 12Ld)$，小模型绑定输入输出、大模型不绑定。
- [3.3 节](3.3_position_encoding.md)：无掩码的注意力看不出顺序，位置必须在打分之前进入；今天默认在每层注意力内部用 RoPE 注入相对位移。
- [3.4 节](3.4_feedforward.md)：前馈网络是一层参数的主体（三分之二到八成），今天默认是无偏置的 SwiGLU；起作用的是门控，不是激活曲线。
- [3.5 节](3.5_residual.md)：残差把每层变成对通路的增量修正，网络像许多浅路径的集成；代价是尺度随深度按 $\sqrt{2L}$ 增长。
- [3.6 节](3.6_layer_norm.md)：归一化提供尺度不变性，放在哪里比用哪一种更要紧；今天默认是 Pre-Norm 加 RMSNorm。
- [3.7 节](3.7_full_architecture.md)：零件接成编码器、解码器与三种变体，再用 $12Ld^2$、$6ND$、$2N$ 与 $T/12d$ 四条速算式给出量级与失效边界。
- [3.8 节](3.8_gpt_inference_flow.md)：用一个可手算的模型把 Prefill 与 Decode 逐格算一遍，说明 KV 缓存为什么成立，以及 Prefill 受算力限制、Decode 受显存带宽限制的原因。

# 第六章：训练技术的原理

确定预训练目标和架构之后，还要让训练有效地收敛。本章的主线是一把尺子：Adam 把每个参数每步的位移钉在学习率 $\eta$ 的量级，并且有一个只由 $\beta$ 决定的上界。学习率调度安排这个尺度随时间怎样变，梯度裁剪与 logits 约束防止它所依赖的状态和数值尺度失控，权重衰减的时间尺度 $1/(\eta\lambda)$、μP 按宽度缩放学习率，管的也是它；批量与序列长度则决定每一步看多少数据、占多少显存。

本章沿着四个问题展开。各节里标为“进阶”的段落多是工程细节，或依赖[第七章](../07_distributed_training/README.md)以后的内容，第一遍阅读可以跳过。

- [6.1 节](6.1_loss_optimizer.md)：损失怎样变成一次参数更新，Adam 为什么是默认优化器，这个“默认”近来又为什么被动摇？
- [6.2 节](6.2_lr_schedule.md)：Adam 已自适应各参数步长，全局学习率为什么还要先预热再衰减？
- [6.3 节](6.3_regularization.md)：学习率调得再准，异常批次仍会污染 Adam 的状态，logits 仍会随权重范数漂移，怎么按住数值尺度？
- [6.4 节](6.4_batch_sequence.md)：有效批次大小该定到多大，上界由什么决定？序列长度又怎样进入算力与显存这两笔账？

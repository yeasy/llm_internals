# 第六章：训练技术的原理

确定预训练目标和架构之后，还要让训练过程有效地收敛到良好的解。损失函数的选择、优化器的设计、学习率的调度和正则化策略看起来“只是超参数调整”，背后既有数学原理，也有大量工程经验。

本章解析这些训练技术的原理，沿着四个问题展开：

- [6.1 节](6.1_loss_optimizer.md)：Adam 为什么是默认优化器，这个“默认”近来又为什么被动摇？
- [6.2 节](6.2_lr_schedule.md)：Adam 已自适应各参数步长，全局学习率为什么还要先预热再衰减？
- [6.3 节](6.3_regularization.md)：学习率调得再准，异常放大的梯度照样能毁掉训练，怎么按住它？
- [6.4 节](6.4_batch_sequence.md)：有效批次大小该定到多大，上界由什么决定？

# 第十二章：编码器系列模型

第三部分的整套推理服务都架在“逐词元把回答生成出来”这个前提上。文本分类、关系抽取、语义相似度这类任务并不需要生成，只需要一份好的文本表示。去掉因果掩码、让每个位置都读到整句的编码器，正是为这件事设计的。

本章按“基线 → 定向修补”组织：[12.1 节](12.1_bert.md)的 BERT 是基线，后两节各自处理它留下的一项问题：[12.2 节](12.2_roberta_albert.md)处理预训练任务与参数量，[12.3 节](12.3_longformer_bigbird.md)前半处理 512 词元的长度上限，后半转向编码器今天的主要用途：句向量、检索与重排序，并算出编码器相对解码器的成本差距。可顺序通读，也可只查用得上的那一节。

各节都把公开配置逐项加成参数量与计算量，算式可以用计算器复核。标有“进阶”的提示块与段落是口径辨析和逐位对账，第一遍可以跳过，不影响后文。

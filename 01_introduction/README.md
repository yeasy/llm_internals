# 第一章：从序列建模到 Transformer

本章的主线是一把尺子。一个序列模型要接受任意长度的输入，要在任意距离上建立依赖，计算代价要可以承受；其中计算代价要分成总运算量和必须排队的顺序步数两个量。Transformer 的每一处设计都对应前一代方案在这把尺子上的一条具体不足，本章因此按时间顺序，用同一把尺子逐个衡量 RNN、CNN、注意力与 Transformer。

[1.0 节](1.0_technology_map.md)是全书的地图，定位 GPU、集群、训练框架、推理引擎与 Agent 的关系，供后续阅读时回查。其余各节的结论如下：

- [1.1 节](1.1_seq_challenge.md)：语言模型就是反复预测下一个词元；“计算效率”要拆成总计算量与顺序步数，两者可以方向相反。
- [1.2 节](1.2_rnn_cnn_limits.md)：RNN 输在连乘衰减与逐步排队，LSTM 的加法通路只缓解了前者；卷积能并行，但两个位置要隔很多层才能相遇。
- [1.3 节](1.3_attention_birth.md)：Seq2Seq 的瓶颈在时机而不在容量；注意力把“读哪里”推迟到解码时，路径长度降到 1，代价是保留全部可读状态。
- [1.4 节](1.4_transformer_idea.md)：拿掉循环之后训练可以并行，生成仍然串行；一层的运算量是 $$24nd^2 + 2n^2d$$，常见长度下并不比循环网络省，快在顺序步数是常数。
- [1.5 节](1.5_milestones.md)：此后的进步来自预训练、规模定律以及用法与系统的六次转折，架构本身只换了几处零件。

本章只建立判据与脉络，自注意力本身怎么算留给[第二章](../02_attention/README.md)。

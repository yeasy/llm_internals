# 第四章：位置编码的设计哲学

[第三章](../03_components/3.3_position_encoding.md)解释了位置编码存在的必要性：自注意力是置换等变的，必须显式注入位置信息。本章围绕一个问题展开：位置信息从哪里进入注意力计算。答案依次是加到嵌入上（正弦编码、可学习编码）、乘到每一层的查询和键上（RoPE）、加到注意力分数上（ALiBi、T5 偏置），直到完全不写（NoPE）。

衡量各方案的尺子只有一把：超出训练长度时还剩多少能力。贯穿全章的规律是，外推边界由训练覆盖决定。正弦编码的低频维、位置表靠后的行、RoPE 没有转满一圈的低频对，失效的都是训练中没有覆盖到的部分。今天的默认方案是 RoPE，长度靠大底数加长序列续训解决。

- [4.2 节](4.2_learnable.md)：让模型自己学位置向量，参数几乎不花钱，代价落在哪里？
- [4.3 节](4.3_rope.md)：RoPE 对每个向量做的旋转只依赖绝对位置，分数为什么只依赖相对距离？既然如此，为什么它仍然外推失败，长度又怎样补回来？

## 8.3 DPO 与新型对齐：从复杂到简洁的演化

**直接偏好优化**（Direct Preference Optimization，DPO）把 RLHF 的四个模型删到两个。依据是一个等式：KL 正则下奖励与最优策略一一对应，“先学奖励再做 RL”因此可以折叠成“让策略直接拟合偏好”，语言模型自己就是奖励模型，损失就是成对分类损失。换来的是无采样、无价值网络、几乎只剩一个超参数 $\beta$，7B 规模的模型状态从 252 GB 降到 126 GB（表 8-4）；失去的是在线性，隐式奖励只在数据覆盖处受约束，而且只约束优劣之差。实践上学习率比 SFT 再低一个量级，盯住优回答对数概率的绝对值以识别似然位移，并对长度做归一化。偏好数据固定、目标是风格与格式时它是默认选择；[Tülu 3](https://arxiv.org/abs/2411.15124) 的公开流程就是 SFT 之后接长度归一化 DPO，再接 RLVR。

### 8.3.1 DPO 的核心洞察

**KL 约束下的最优策略与奖励函数一一对应，因此奖励模型可以被解析地吸收进语言模型的参数化里**。省掉的不只是奖励模型的训练，还有 PPO 的整个采样-估值循环。

#### 从 RLHF 目标到 DPO 损失的推导

**第一步：Bradley-Terry 偏好模型。** 与 8.2.2 的奖励模型同一个假设：给定两个回答 $y_1$ 和 $y_2$，人类偏好 $y_1$ 的概率由奖励差决定。

$$P(y_1 \succ y_2 \mid x) = \sigma\big(r(x, y_1) - r(x, y_2)\big)$$

**第二步：KL 约束下的最优策略。** RLHF 的目标是在 KL 约束下最大化期望奖励：

$$\max_{\pi} \mathbb{E}_{y \sim \pi}[r(x, y)] - \beta\, \mathrm{KL}\big[\pi \,\|\, \pi_{\text{ref}}\big]$$

这个问题有闭式解。把 KL 按定义展开、整个目标除以 $-\beta$，最大化变成最小化：

$$
\min_\pi \mathbb{E}_{y\sim\pi}\left[\log\frac{\pi(y\mid x)}{\pi_{\text{ref}}(y\mid x)} - \frac{1}{\beta}r(x,y)\right]
$$

定义配分函数（归一化常数）$Z(x) = \sum_y \pi_{\text{ref}}(y\mid x)\exp\big(r(x,y)/\beta\big)$ 与

$$\pi^*(y\mid x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y\mid x) \exp\left(\frac{r(x,y)}{\beta}\right)$$

由于 $\pi_{\text{ref}}\exp(r/\beta) = Z\,\pi^*$，括号里的两项合成一个对数：

$$
\log\frac{\pi}{\pi_{\text{ref}}} - \frac{r}{\beta} = \log\frac{\pi}{\pi_{\text{ref}}\exp(r/\beta)} = \log\frac{\pi}{Z\,\pi^*} = \log\frac{\pi}{\pi^*} - \log Z
$$

对 $y \sim \pi$ 取期望，第一项就是 $\pi$ 到 $\pi^*$ 的 KL。目标就变成

$$
\min_\pi \mathbb{E}_{x}\Big[\mathrm{KL}\big(\pi(y\mid x) \,\|\, \pi^*(y\mid x)\big) - \log Z(x)\Big]
$$

$Z(x)$ 与 $\pi$ 无关，KL 非负且仅在两分布相同时为零，所以最小值在 $\pi = \pi^*$ 处取到。$Z(x)$ 的求和遍历全部可能的回答，无法计算，这是它碍事的地方。

对 $\pi^*$ 的定义式两边取对数再移项，反解出奖励函数：

$$r(x, y) = \beta \log \frac{\pi^*(y\mid x)}{\pi_{\text{ref}}(y\mid x)} + \beta \log Z(x)$$

**第三步：代入消除奖励模型。** Bradley-Terry 只依赖两个回答的奖励**差**，$\beta\log Z(x)$ 对同一个 $x$ 下的两个回答完全相同，相减即消。偏好概率里只剩 $\pi^*$ 与 $\pi_{\text{ref}}$。再换参数化：把正在训练的 $\pi_\theta$ 放在 $\pi^*$ 的位置上，对偏好数据做最大似然；调 $\pi_\theta$ 就是在调它背后那个奖励，拟合好之后 $\pi_\theta$ 本身就是该奖励下的最优策略。于是得到 DPO 损失：

$$\mathcal{L}_{\text{DPO}} = -\log \sigma\left(\beta \log \frac{\pi_\theta(y_w\mid x)}{\pi_{\text{ref}}(y_w\mid x)} - \beta \log \frac{\pi_\theta(y_l\mid x)}{\pi_{\text{ref}}(y_l\mid x)}\right)$$

其中 $y_w$ 是被偏好的回答，$y_l$ 是不被偏好的回答，$\pi_\theta$ 是正在训练的模型，$\pi_{\text{ref}}$ 是参考模型（通常是 SFT 后的模型），$\beta$ 控制偏离参考模型的程度。记 $\hat r_\theta(x,y) = \beta\log\frac{\pi_\theta(y\mid x)}{\pi_{\text{ref}}(y\mid x)}$ 为**隐式奖励**，损失就与 8.2.2 的 $\mathcal{L}_{RM}$ 完全同形。**DPO 并没有绕开奖励模型，它把语言模型自己当成了奖励模型。**

参考模型取 SFT 模型，因为偏好对里的回答通常由它采样，以它为锚，策略被拴在数据覆盖的分布附近；[DPO 论文](https://arxiv.org/abs/2305.18290)拿不到 SFT 模型时，先在优回答上做最大似然得到一个参考模型。偏好对的来源决定了这层偏移有多重：Tülu 3 的偏好对这样得到：自己的 SFT 模型与其他模型各写回答，判官模型（GPT-4o）按有用性、指令遵循、诚实、真实四个维度给每条回答单独打 1 到 5 分，取均分最高的为优、从均分较低的回答里随机取一条为劣；消融显示，混入自身 SFT 模型的回答（on-policy 数据，训练仍是离线的）能提升 DPO 的效果。

#### 梯度：哪些样本在推动更新

对 $\theta$ 求导，DPO 论文把结果写成三个带注解的因子：

$$
\nabla_\theta\mathcal{L}_{\text{DPO}} = -\beta\,\underbrace{\sigma\big(\hat r_\theta(x,y_l) - \hat r_\theta(x,y_w)\big)}_{\text{隐式奖励排错得越厉害，权重越大}}\Big[\underbrace{\nabla_\theta\log\pi_\theta(y_w\mid x)}_{\text{提高 } y_w \text{ 的概率}} - \underbrace{\nabla_\theta\log\pi_\theta(y_l\mid x)}_{\text{降低 } y_l \text{ 的概率}}\Big]
$$

方括号里是方向：抬高优回答、压低劣回答。sigmoid 是权重：排对且排得很开的样本自动降权，排反了的样本吃满梯度。论文指出去掉这个权重会让模型退化。

#### 一个训练步：四次前向与一格手算

**序列对数概率怎么来。** 公式里的 $\log\pi(y\mid x)$ 是整条回答的对数概率，等于回答各词元条件对数概率之**和**：

$$\log\pi(y\mid x) = \sum_{t\in\text{回答}}\log p(y_t\mid x, y_{<t})$$

求和范围就是 8.1.2 的损失掩码。这里是求和而不是平均，它是后面长度偏差的来源。

**一个训练步做四次前向**：策略与参考对 $y_w$、$y_l$ 各一次。参考侧不回传梯度，可以在训练前把全数据集的参考对数概率预计算好，参考模型就不必常驻显存，7B 规模下从 126 GB 降回 112 GB（表 8-4）；多轮迭代式 DPO 每轮都要重算。

**一格手算。** 取 $\beta = 0.1$。设某一对样本上：

| 量 | 优回答 $y_w$ | 劣回答 $y_l$ |
| --- | ---: | ---: |
| $\log\pi_\theta$ | −40 | −55 |
| $\log\pi_{\text{ref}}$ | −42 | −50 |
| 对数比 | +2 | −5 |
| 隐式奖励 $\hat r = \beta \times$ 对数比 | +0.20 | −0.50 |

表 8-6：一对偏好样本上 DPO 各个中间量的取值，$\beta = 0.1$。对数比是策略与参考在整条回答上的对数概率之差。

边际为 $0.1 \times (2 - (-5)) = 0.7$；$\sigma(0.7) = 0.668$；损失为 $-\ln 0.668 = 0.403$；梯度权重为 $1 - 0.668 = 0.332$。

训练刚开始时 $\pi_\theta = \pi_{\text{ref}}$，边际为 0，损失为 $\ln 2$，梯度权重为 0.5，与 8.2.2 的奖励模型同一个起点。排错的样本损失更大：对数比换成 −2 与 +3 时，边际为 −0.5，损失为 0.974，梯度权重升到 0.623。

### 8.3.2 DPO 的取舍

删掉奖励模型与采样循环，收益落在三处：流水线退化成一个成对分类问题；显存只剩策略与参考（表 8-4）；没有采样，也就没有 on-policy 分布漂移与 8.2.3 的训练—推理失配。代价集中在被吸收进参数里的那个隐式奖励上。

#### 代价与失效情形

**隐式奖励同样会被过度优化。** 8.2.3 的机制只依赖“代理目标不等于真实目标”，不依赖奖励模型是不是一个独立网络。DPO 的代理目标 $\hat r_\theta$ 同样可以被推到离参考模型很远的地方。优、劣回答上的对数比是训练的副产品，可以直接画出来；拿不到的是策略自己采样分布上的 KL，因为 DPO 不采样，要定期采样另行估计。所以“DPO 更稳”指的是少了几个可能崩的部件，不是更抗 Goodhart 定律（代理指标一旦成为优化目标，就不再可靠地代表真实目标，图 8-3 即是一例）。

**似然位移（likelihood displacement）**。损失只约束差值，不约束绝对值：$\log\pi_\theta(y_w)$ 与 $\log\pi_\theta(y_l)$ 同时下降，只要后者降得更快，损失照样下降。[Razin 等人](https://arxiv.org/abs/2410.08847)的例子是训练模型偏好 No 胜过 Never，可能显著抬高 Yes 的概率。概率质量流向训练集之外，方向不受控，日志上的征兆是优回答的对数概率在往下走。

**离线数据的分布偏移**。隐式奖励只在数据覆盖到的地方被约束，策略却恰恰会往分布外跑。这是与在线 PPO 的根本区别，也是迭代式、在线式 DPO 的动机：每轮用当前策略重新采样、重新标注。

**确定性偏好下 KL 约束失效**。[IPO 的分析](https://arxiv.org/abs/2310.12036)指出，经验偏好接近确定（某对总是同一个方向）时，损失要求 $\sigma(\Delta) \to 1$，只有边际 $\Delta \to \infty$ 才能逼近；$\log\pi_\theta(y_w\mid x)$ 不超过 0，要让 $\Delta$ 无限增大只能把劣回答的概率压向 0，KL 正则实际上不起作用。数据少时这种“经验上确定”非常容易出现。

**长度偏好放大**。进入损失的是对数比 $\log\frac{\pi_\theta}{\pi_{\text{ref}}}$，它按词元累加：长回答在很多词元上各挪一点，就能累出很大的边际，损失最容易靠这种方式下降。再叠加偏好数据里优回答偏长（人类标注和 LLM 判官都有这个倾向），模型就学到了变长。

| 维度 | PPO 式 RLHF | DPO |
| --- | --- | --- |
| 数据 | 在线采样，每轮由当前策略生成 | 离线成对偏好数据 |
| 训练中的模型数 | 4（策略、价值、参考、奖励） | 2（策略、参考），参考可预计算后去掉 |
| 7B 模型状态显存 | 252 GB | 126 GB（或 112 GB） |

| 分布外约束 | 采样即在分布内，KL 可监控 | 无约束，隐式奖励在数据覆盖外自由 |
| 主要超参数 | $\epsilon$、$\beta$、$\gamma$、$\lambda$、批与小批、内轮数 | $\beta$、学习率、轮数 |

### 8.3.3 更多对齐方法

DPO 之后的变体很多，在线 RL 一侧也有只动一处的改法。读法是问一句：**它改了原目标里的哪一项。**

| 方法 | 改动的那一项 | 换来什么 | 代价 |
| --- | --- | --- | --- |
| IPO | 把 $-\log\sigma(\cdot)$ 换成对边际的平方损失 | 边际不再能无限增大，确定性偏好下 KL 约束仍有效 | 拟合偏好的能力弱于 BT |
| SimPO | 隐式奖励改为**平均**对数概率，并去掉参考模型；BT 里加一个目标边际 $\gamma_{\text{SimPO}}$ | 奖励与生成时的打分口径一致，长度偏差被归一化掉，省掉参考模型 | 多一个 $\gamma_{\text{SimPO}}$ 要调，失去 KL 到参考的锚 |
| KTO | 不用成对数据，改用单条的“好/坏”二元标注，按前景理论的效用函数建模 | 标注更易得；论文报告 1B 到 30B 上匹配或超过成对方法 | 需要指定参考点，正负样本比例敏感 |
| ORPO | 把一个对数几率比惩罚项直接加到 SFT 的负对数似然上 | SFT 与偏好优化合成一个阶段，无参考模型 | 与 SFT 共用学习率与数据，调参耦合 |
| GSPO | 重要性比率与裁剪从词元级改为**序列级** | 稳定 MoE 的 RL 训练，不再需要路由重放 | 裁剪范围要缩小几个数量级并重调；越界时整条回答失去梯度 |
| CISPO | 裁剪的对象从词元的更新项改为重要性权重本身，并对权重停止梯度 | 比率越界的词元仍贡献梯度 | 梯度估计略有偏差 |

表 8-8：几种对齐目标变体各自改了哪一项。前四行为离线偏好优化；后两行为在线 RL，改的是 [8.2.4 节](8.2_rlhf.md) GRPO 目标里的概率比 $\rho_{i,t}$ 与裁剪。IPO 见 [Azar 等人](https://arxiv.org/abs/2310.12036)，SimPO 见 [Meng 等人](https://arxiv.org/abs/2405.14734)，KTO 见 [Ethayarajh 等人](https://arxiv.org/abs/2402.01306)，ORPO 见 [Hong 等人](https://arxiv.org/abs/2403.07691)，GSPO 见 [Qwen 团队](https://arxiv.org/abs/2507.18071)，CISPO 见 [MiniMax-M1 技术报告](https://arxiv.org/abs/2506.13585)。SimPO 的目标边际在论文里记作 $\gamma$，这里加下标以区别于 8.2 的折扣因子。后两行的机制与数字见 8.2.4。

另有一支不改损失而改数据来源：[Constitutional AI](https://arxiv.org/abs/2212.08073) 是 Anthropic 早于 DPO 提出的 RLAIF 流程，用 AI 依据一组原则自我批评、自我修订并给出偏好，减少对人工标注的依赖。它并非 DPO 的变体，替换的是偏好标签的生产方式。

**长度这一项值得单独处理。** Tülu 3 在同一批数据上对比 DPO、SimPO 与长度归一化 DPO，最终选用长度归一化 DPO，只有它在总体上超过基线检查点；这条结论只在该数据混合上验证过。

### 8.3.4 指令层级训练：对抗性 RL 对齐的新方向

前面的方法对齐的是“输出是否符合偏好”。模型部署在多角色场景（系统提示、开发者消息、用户输入、工具返回）后，还要对齐另一件事：**不同优先级的指令冲突时，听谁的**。这就是**指令层级**（Instruction Hierarchy，IH），信任排序是 system ≻ developer ≻ user ≻ tool，低优先级指令只在与高优先级约束兼容时才被遵从。单角色问答上的偏好数据不覆盖这种冲突，所以充分对齐的模型面对提示注入（把指令藏在用户输入或工具返回里，诱使模型越权执行）仍然脆弱。

[IH-Challenge](https://arxiv.org/abs/2603.10521) 用 8.2 的 RL 训练它，三条设计各对一个难点：用 Python 评分代码代替 LLM 判官，消除判官可被奖励黑客利用的漏洞；训练中由冻结的攻击者模型在线生成冲突消息；加入把正常请求改写成“看起来像攻击”的任务，防止模型学会一律拒绝。在 GPT-5-Mini 上，IH 鲁棒性在 16 个基准上平均从 84.1% 升到 94.1%（10.0 个百分点），知识与数学基准基本不动，对话偏好类指标掉 5 到 6 个点（单篇论文的快照数字，登记见[附录 A.5](../appendix/a5_volatile_facts.md)）。这说明一部分安全失败来自模型没分清指令优先级，训练可以直接改善；工具权限隔离、上下文隔离、监控与人工响应等系统级防护仍不可省。

### 8.3.5 对到实现

**$\beta$ 的量级取决于奖励怎么定义。** DPO 论文的默认值是 0.1（TL;DR 摘要任务用 0.5）。它与 8.2 的 KL 系数是同一个量的两种出场方式：PPO 里乘在逐词元 KL 惩罚上，DPO 里乘在序列对数比上，不可直接照搬。长度归一化变体尤其如此：Tülu 3 用的 $\beta$ 是 5，比原始 DPO 大一个半数量级，因为对数比已被序列长度除过一次。$\beta$ 越小，允许离参考越远；取值要配合保留集质量与定期采样估出的 KL 来定。

**学习率要比 SFT 再低约一个数量级。** Tülu 3 的 8B 配方里 SFT 用 $5\times10^{-6}$、DPO 用 $5\times10^{-7}$，70B 是 $2\times10^{-6}$ 与 $2\times10^{-7}$，DPO 只跑 1 轮。沿用 SFT 的学习率，表现为优回答的对数概率快速崩塌。

**看哪几条曲线。** 损失从 $\ln 2$ 起步，隐式奖励的准确率（边际为正的比例）从 50% 起步；同时单独画出 $\log\pi_\theta(y_w)$ 的绝对值。前两条向好而第三条快速下跌，就是似然位移正在发生。

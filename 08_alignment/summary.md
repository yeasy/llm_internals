## 本章小结

**后训练只是一小段位移。** SFT 见到的词元比预训练少四到五个数量级，所以全参数微调的学习率在 $10^{-6}$ 到 $10^{-5}$ 量级、只跑一到两轮；DPO 再低一个量级；LoRA 反过来约高 10 倍。走得太远，代价都出在训练损失看不见的地方。

**SFT 教的是映射，不是知识。** 损失与预训练同形，区别只在掩码：只对回答（含结束词元）计损失。效果由提示的多样性决定，条数在其次；最常见的失败出在模板、结束词元与掩码的错位上，三者都不反映在损失上。

**偏好比示范便宜，但代理奖励越优化越偏。** RLHF 把成对比较拟合成标量奖励（BT 损失从 $\ln 2$ 起步，准确率上限由标注一致率决定），再做以优势为权重的 SFT；KL 锚、GAE 与裁剪都是为了把每步与总偏移量限制住。真实奖励随 $\sqrt{\mathrm{KL}}$ 先升后降，要监控的是 KL，不是步数。

**可验证奖励是推理能力的主干。** 奖励换成规则，价值网络换成组内基线（GRPO，7B 下省掉 112 GB），风险随之从攻击奖励模型变成攻击验证器与归一化分母。只有组内有对有错的题才提供信号，题库难度要跟着策略水平走；长度涨而 reward 不涨，先查损失的分母。

**离线偏好优化把四个模型减到两个。** DPO 让语言模型自己充当奖励模型，换来无采样、近乎只有一个 $\beta$；代价是隐式奖励只在数据覆盖处受约束、只约束差值，失效形态是似然位移、长度偏好与确定性偏好下的 KL 失效。偏好数据固定、目标是风格与格式时，它是默认选择。

**LoRA 能否追平全参数微调，看容量。** 适配器每参数约能存 2 比特信息；数据要写入的信息远小于容量时（RL、中小规模 SFT）追得平，大规模持续预训练会掉队。覆盖哪些层比秩重要，全部线性层是默认；它省模型状态，不省激活。

**四种失败都不在训练损失里。** 遗忘与学到的东西绑在同一根杠杆上，良性数据微调一轮就可能把安全拒答削掉一大块；对齐税要靠拌回宽分布数据，调大 KL 修不好。所以要在训练前固定通用能力回归集（含安全拒答与开放问答），前后配对比较：差值的标准误约为 $\sqrt{b+c}/n$，只由翻转题数决定；停点由事先定好的交换比决定。

**分数是模型乘以评测流水线。** 基座模型用对数似然打分，对话与推理模型用零样本、套聊天模板的生成式打分，两组分数不可相比；题目、口径、模板、解码、抽取规则、批大小钉死之后，前后分数才可比。污染检测分三层：$n$-gram、嵌入检索加判定、换新题。

**今天默认怎么做。** 先 SFT（混合数据，按词元归一化，掩码与模板逐词元核对）。通用助手的开放配方（Tülu 3）接着在固定偏好对上做长度归一化 DPO，再对能自动判对错的任务做 RLVR；推理模型（DeepSeek-R1、Qwen3）不设单独的离线偏好阶段，冷启动 SFT 后直接做 GRPO 一族的推理 RL，再以一段 SFT 和一轮通用 RL 收尾，有用性与无害性仍用奖励模型（两种形态见本章导读）。数据量不大或做 RL 时用 LoRA，覆盖全部线性层，学习率取全参数微调的约 10 倍；数据量大时换回全参数。每一步都先固定回归集，再开始训练。

全章都把“生成”当成现成的一步（8.2 里 rollout 直接交给推理引擎），没有说明对齐后的权重每一步给出的词元概率，怎样变成用户看到的那句话。至此，第二部分“训练篇”结束。

2. 一次排序 $K = 4$ 个回答，能拆成几对比较？某一对上 $r_w = 2.0$、$r_l = 1.0$，奖励模型的损失是多少？为什么训练刚开始时损失约为 0.693？（[8.2.2](8.2_rlhf.md)）
3. 为什么说策略梯度是“以优势为权重的 SFT”？在 $\epsilon = 0.2$ 的裁剪目标里，$\rho_t = 1.3$、$A_t = +2$ 时梯度为零，$\rho_t = 1.3$、$A_t = -2$ 时梯度却保留，这种不对称有什么用？（[8.2.2](8.2_rlhf.md)）
4. GRPO 的一组奖励是 $[1, 0, 0, 0]$，四条回答的优势各是多少？整组全对时优势为什么全为零，此时还能不能说“总梯度为零”？（[8.2.4](8.2_rlhf.md)）

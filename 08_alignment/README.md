# 第八章：后训练：从指令微调到推理强化

问一个刚完成预训练的模型“法国的首都是什么？”，它可能答“巴黎”，也可能顺着写出下一道题“德国的首都是什么？”。预训练时，模型练的是根据上文预测接下来会出现什么。这两种接法都说得通。给模型看一批问答示范，让它遇到提问时更常给出回答，是后训练的一种做法。

如果手里已有会对话的模型，先把要求写进提示。例如只要城市名，就写“只写中文城市名”，再换几个国家试一试。模型已经能稳定做到，就可以用。反复出现同一类错误时，再考虑用训练纠正。

第一次读，可以先看[监督微调怎样教模型回答](8.1_sft.md)、[强化学习怎样用得分更新模型](8.2_rlhf.md#rl-training-loop)，再读[LoRA 改的是哪些参数](8.4_peft.md)。手里有模型和数据时，可以直接从[第一次微调的步骤](#post-training-start)开始。

## 后训练、微调和 LoRA 各指什么

**后训练**（Post-training）是预训练之后，为了让模型更好地按指令回答、使用工具或推理而进行的训练。指令示范也可以提前放进基础训练。艾伦人工智能研究所（Ai2）的语言模型 [Olmo 3](https://allenai.org/blog/olmo3) 就在基础训练的后段加入了指令示范和推理过程。单独安排后训练，方便在模型能作答之后收集反馈，也方便从同一份权重出发，训练出适合不同任务的模型。

**微调**（fine-tuning）指以已有模型为起点继续训练。用示范训练叫**监督微调**（SFT）。做 SFT 时，可以更新模型的全部参数，也可以加上[低秩适配器（LoRA）](8.4_peft.md)，固定原有权重，只训练附加的少量参数。SFT 决定用什么信号教模型，LoRA 决定训练时改哪些参数。

## 示范、偏好和奖励

### 先用示范教模型作答

把“法国的首都是什么？”和“巴黎”配在一起，就是一条 SFT 数据。训练时让模型读到问题，再提高它生成示范答案的概率。问答、摘要、信息提取等任务都可以这样教。[8.1 节](8.1_sft.md)有数据样例和逐词元计算损失的过程。

### 能核对结果时，让模型多试几次

数学题往往有几种正确解法。先用示范让模型学会怎样作答，再让它自己解题。每次解完，由程序检查答案，训练程序按得分更新模型。这样，模型自己找到的正确解法也能得到反馈。这叫**可验证奖励的强化学习**（RLVR）。工具调用也可以这样练，前提是任务能反复运行，结果能核对，见 [14.5.7 节](../14_future_trends/14.5_agent_tool_use.md#agent-tool-training)。

[组相对策略优化（GRPO）](8.2_rlhf.md#rl-verifiable-rewards)是常用的更新方法之一。它让模型对同一道题多答几次，用同组平均分作参照。高于平均分的回答会得到正的更新权重，低于平均分的回答会得到负的权重。如果每次答得都一样好，或者都一样差，这组得分就无法区分好坏。[A.7 的首都问答实验](../appendix/a7_framework_recipes.md#grpo-capital-recipe)演示数据、判分和更新过程。

### 两份回答都对，怎么教模型选

“巴黎”和“法国的首都是巴黎”都答对了。如果希望模型用完整句子，可以选第二份。把原问题、两份回答和这个选择存下来，就是一条偏好数据。已经有一批标好优劣的回答对，可以用[直接偏好优化（DPO）](8.3_dpo.md)训练。它通过比较两份回答在当前模型和参考模型下的概率，学习人选中的写法。

如果想给训练中生成的新回答打分，也可以用人工比较先训练一个评分模型。OpenAI 的 [InstructGPT](https://arxiv.org/abs/2203.02155) 用的就是这套经典的**基于人类反馈的强化学习**（RLHF）。生成一批回答的成本较高，可以用这批回答更新几次。模型每更新一次，生成旧回答的概率就可能变化。[近端策略优化（PPO）](8.2_rlhf.md#ppo-update-intro)用采样时的概率作参照，限制继续沿同一方向改动的收益。[8.2 节](8.2_rlhf.md)用首都问答算出一次具体的更新。

| 手头有什么 | 可以怎么训练 | 看什么结果 |
| --- | --- | --- |
| 输入和正确示范 | [监督微调（SFT）](8.1_sft.md) | 在没见过的输入上分别检查答案和格式 |
| 可反复运行的任务和可靠的自动判分 | [可验证奖励的强化学习（RLVR）](8.2_rlhf.md#rl-verifiable-rewards) | 用反例检查判分，再比较加了强化学习后是否做得更好 |
| 同一输入下已经标好优劣的回答对 | [直接偏好优化（DPO）](8.3_dpo.md) | 在未见过的回答对上检查偏好，再看实际生成的回答 |
| 有教师模型能根据学生已经写出的内容，给出下一词元的概率 | [在线策略蒸馏（OPD）](#on-policy-distillation) | 用未见任务检查学生是否学到了目标能力 |

## 怎么用自己的模型开始

以让通义千问（Qwen）根据论文正文写摘要为例，先明确摘要要交代什么，以及哪些错误不能接受。原模型可以来自本地权重目录，也可以是平台支持微调的模型。

1. **先测原模型。** 固定提示和生成设置，用一批验证论文看原模型经常漏掉哪些主要结论，数字或单位是否写错，是否把相关性写成因果关系。模型已经达到要求，就可以直接使用。
2. **用审核过的摘要做 SFT。** 每条训练记录包含任务要求、论文正文和摘要。同一篇论文及其不同版本放在同一组。用验证集挑选方案，最终测试集单独保留。第一次可以用 LoRA 只训练适配器。[A.7 的 Qwen 论文摘要配方](../appendix/a7_framework_recipes.md#qwen-paper-summary)给出了样本、训练和前后对照的做法。
3. **能可靠判分，再试 GRPO。** 例如预先为每篇论文列出必须覆盖的结论及其原文位置，用答得好和答得差的摘要检验评分规则。规则能分清候选摘要的好坏时，从 SFT 的结果继续训练。如果现成的反馈是人工选出的优、劣摘要对，可以试 DPO。
4. **等方案确定，再做最终测试。** 用相同的论文、提示、生成设置和评分规则比较各个版本。只有格式变好、事实错误仍多时，应先解决事实错误。数据怎样划分、如何检查原有能力是否下降，见 [8.5 节](8.5_practice.md)。摘要怎样评分，见 [8.6 节](8.6_evaluation.md)。

| GRPO | [TRL 的 GRPOTrainer](../appendix/a7_framework_recipes.md#grpo-capital-recipe) |

## 公开模型怎样把这些方法接起来

[DeepSeek-R1](https://arxiv.org/abs/2501.12948) 和通义千问团队的 [Qwen3 旗舰模型](https://arxiv.org/abs/2505.09388) 先用解题示范做 SFT，再用 GRPO 训练推理。之后，DeepSeek-R1 从模型生成的答案中筛出正确答案，用于下一轮 SFT。Qwen3 在随后的 SFT 中学习在详细推理和直接作答之间切换。最后，两者都把强化学习扩展到更多类型的任务，结合规则与模型打分。

<a id="on-policy-distillation"></a>

要把已经学会的能力传给另一个模型，可以用教师模型的输出指导学生，这叫**蒸馏**。如果学生一开头就选了与教师示范不同的表达，单独看两份完整答案，很难告诉学生当前这一步怎么接。**在线策略蒸馏**（On-Policy Distillation，OPD）先让学生自己生成。教师读到学生已经写出的内容，再给出下一个词元的概率，用来指导这一步的训练。计算过程见 [10.5.2 节](../10_inference_optimization/10.5_pruning_distillation.md)。

DeepSeek 发布的多模态模型 [DeepSeek-V4.1-Flash](https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash) 先用 SFT 学示范，再用强化学习练习完成任务，最后用在线策略蒸馏。模型卡说明，这一版着重改了强化学习任务和环境的生成流程。

[Kimi K3](https://arxiv.org/html/2607.24653v2#S4.SS1.SSS3) 的报告给出为什么要用多个教师。团队先用 SFT 建立基础能力，再用强化学习训练各有专长的模型，最后让一个学生按任务向不同的教师学习，把这些能力合到同一个模型里。

有固定偏好数据时，仍可用 DPO。Ai2 在 Meta 的 Llama 3.1 上继续训练得到 [Tülu 3](https://arxiv.org/abs/2411.15124)，先用了约 94 万条示范做 SFT，再用标好优劣的答案对做 DPO，随后用可验证奖励做强化学习。Ai2 的指令模型 [Olmo 3.1 32B Instruct](https://huggingface.co/allenai/Olmo-3.1-32B-Instruct) 也有独立的 DPO 阶段。

PPO 仍用于部分强化学习配方。例如 [CAMG-RL](https://arxiv.org/abs/2609.34422) 用异步 PPO 训练模型在长任务中记住并找回信息。想用小张量核对标签掩码、LoRA、DPO 和组内优势，可做 [A.6 的练习](../appendix/a6_practice_path.md)。

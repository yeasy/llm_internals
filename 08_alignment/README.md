# 第八章：从预训练到对齐：让模型有用且安全

预训练产出的基础模型拥有丰富的知识，却**不知道如何与人交互**，会无差别地续写任何文本，包括有害内容。把它变成有用、诚实且安全的助手，靠的是**后训练对齐**（Post-training Alignment）。本章的主线是一句话：**后训练只是在预训练解附近移动一小段距离，各种方法的差别在于训练信号从哪里来（示范、偏好、可验证的对错），以及怎样让这段移动既到位又不毁掉已有能力。**

今天公开的后训练流程有两种常见形态，起点都是 SFT，数据是人工标注与合成数据的混合（[Tülu 3](https://arxiv.org/abs/2411.15124) 的 SFT 数据约 94 万条）。通用助手的开放配方以 Tülu 3 为代表，分三步：SFT，在固定的偏好对上做离线偏好优化（长度归一化 DPO），再对能自动判对错的任务做可验证奖励的强化学习（RLVR）。推理模型（[DeepSeek-R1](https://arxiv.org/abs/2501.12948)、[Qwen3](https://arxiv.org/abs/2505.09388)）不设单独的离线偏好阶段：冷启动 SFT 之后直接做推理 RL，目标函数取 GRPO 一族，再以一段 SFT（拒绝采样或思考模式融合得到的数据）和一轮通用 RL 收尾；通用 RL 对可判对错的任务用规则奖励，有用性与无害性仍要靠奖励模型。数据量不大、或者做 RL 时，LoRA 能追平全参数微调。

全章沿着六个问题展开：

- [8.1 节](8.1_sft.md)：只会顺着文本续写的基础模型，怎么学会“被问就答”？
- [8.2 节](8.2_rlhf.md)：开放性问题没有标准答案，好坏该由谁来判定？对错能自动判定时又该怎么训？
- [8.3 节](8.3_dpo.md)：四个模型同时常驻显存的流程，能删到只剩几个？不同来源的指令互相冲突时，模型该听谁的？
- [8.4 节](8.4_peft.md)：训练目标不变，哪些参数才真的值得更新？
- [8.5 节](8.5_practice.md)：训练损失一路向下，为什么模型可能已经坏了？
- [8.6 节](8.6_evaluation.md)：用来判断好坏的那个准确率，本身是怎么算出来的？

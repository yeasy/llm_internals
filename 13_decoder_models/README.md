# 第十三章：解码器系列与主流 LLM

仅解码器（Decoder-Only）的 Transformer 架构已成为当代大语言模型的绝对主流。本章剖析从 GPT 到 Llama、DeepSeek 的技术演进，以及编码器-解码器模型（T5、BART）的设计选择。

本章按谱系而非难度排列：[13.1 节](13.1_gpt_series.md)到 [13.3 节](13.3_deepseek_gemini.md)沿时间线走，从 GPT 的规模扩展，到 Llama 确立的“标准配方”，再到 DeepSeek、Gemini、Claude 这一批前沿模型；[13.4 节](13.4_t5_bart.md)单列编码器-解码器这条并行路线。可顺序通读，也可当模型手册按需跳读。

各节做的是同样三件事：把公开配置读成数字，即参数量、KV 缓存与训练算力三笔账；把代际差异读成设计决策，每处改动换来什么、付出什么；划清公开事实与推测的边界。13.1.7 与 13.3 节涉及混合专家模型（MoE），初次接触的读者可先读 [13.3.5 节](13.3_deepseek_gemini.md)的 Mixtral 对账。标有“进阶”的提示块与段落是逐位对账和口径辨析，第一遍可以跳过，不影响后文。

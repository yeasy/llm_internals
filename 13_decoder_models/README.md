# 第十三章：解码器系列与主流 LLM

本章的主线是一个判断：仅解码器的 Transformer 已经收敛到一套标准配方，各代、各家模型的差别都可以读成“在哪一个部件上，用什么换了什么”。读懂一个模型只需三笔账：参数量决定权重显存，每词元 KV 缓存决定上下文占多少显存，训练算力与每词元激活的参数决定成本。

各节按谱系排列。[13.1 节](13.1_gpt_series.md)讲 GPT：规模涨了三个数量级而架构几乎不动，后训练把续写模型变成助手。[13.2 节](13.2_llama.md)讲 Llama 确立的标准配方，以及“把小模型训到远超算力最优”这个决策。[13.3 节](13.3_deepseek_gemini.md)讲 DeepSeek 等前沿模型在这套配方上换了哪些部件，稀疏模型的总参数与激活参数为什么要分开读。[13.4 节](13.4_t5_bart.md)单列编码器-解码器这条并行路线：它输在缓存形态，不输在参数效率。可顺序通读，也可当模型手册按需跳读。

GPT-4 之后的闭源模型不公开架构，本章对它们只讨论已发表的方法，型号、日期与价格见[附录 A.5](../appendix/a5_volatile_facts.md)。13.1.7 与 13.3 节涉及混合专家模型（MoE），初次接触的读者可先读 [13.3.5 节](13.3_deepseek_gemini.md)的 Mixtral 分解。

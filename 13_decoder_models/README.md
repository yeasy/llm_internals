# 第十三章：解码器系列与主流 LLM

仅解码器（Decoder-Only）的 Transformer 架构已成为当代大语言模型的绝对主流。本章深入剖析从 GPT 到 Llama、DeepSeek 的技术演进，以及编码器-解码器模型（T5、BART）的设计选择。

本章按谱系而非难度排列：[13.1 节](13.1_gpt_series.md)到 [13.3 节](13.3_deepseek_gemini.md)沿时间线走，从 GPT 的规模扩展，到 Llama 确立的“标准配方”，再到 DeepSeek、Gemini、Claude 这一批前沿模型；[13.4 节](13.4_t5_bart.md)单列编码器-解码器这条并行路线。可顺序通读，也可当模型手册按需跳读。

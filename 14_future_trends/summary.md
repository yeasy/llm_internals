## 本章小结

**高效注意力**（稀疏注意力、线性注意力）通过限制注意力范围或核函数近似来突破 $$O(n^2)$$ 的瓶颈，在超长序列场景下尤为重要。

**混合专家模型（MoE）** 通过只激活部分参数实现了“大容量、低计算”的目标，DeepSeek-V3（671B 总参/37B 激活）等模型证明了这一方向的巨大价值。

**状态空间模型（Mamba 等）** 用线性递推替代注意力，复杂度从 $$O(n^2)$$ 降至 $$O(n)$$。**混合架构**将注意力与 SSM 结合，在不同层使用不同机制以兼取两者之长。

**多模态 Transformer** 正在走向统一不同模态的表示与生成，是下一代基础模型的核心方向。

**AI Agent 与工具调用**让 LLM 在宿主系统授权下从被动问答走向受控行动。通过 Function Calling 实现结构化工具调用，以 ReAct 等架构模式组织推理与行动，借助 MCP 等标准化协议降低工具集成成本。Agent 的兴起也对推理引擎提出了长对话管理、状态维持和并发调用等新需求。

**推理时计算扩展**把性能瓶颈从训练阶段部分移到推理阶段。它买到的是串行步数：中间生成确实扩展了仅解码器 Transformer 的计算能力，扩展幅度取决于允许生成多少步。代价可以算清：Llama 3 8B 思考 1 万个词元要 160.6 TFLOPs，在 H100 上至少 48 秒，占 1.22 GiB 的 KV，吃的是延迟与缓存池而不是算力。这种能力靠可自动验证的奖励训出来，DeepSeek-R1 的四个阶段给出了完整样本；验证信号本身分 ORM 与 PRM 两路，而 PRM 在大规模 RL 里的收益抵不过它的开销。部署形态因此走向按难度分配预算，而不是一律加厚。

**长上下文技术**把窗口从 2K 推到百万级，接近三个数量级。三笔开销各有算法。计算的平方项在 $$n = 12d$$ 之后才主导，Llama 3 70B 是 98,304 个词元。KV 缓存每词元 0.3125 MiB，百万词元要 305 GiB。通信则是序列切开之后才出现的一笔，Ring Attention 的重叠条件简化为“块长不小于算力与带宽之比”，跨节点时要求每卡上万个词元。因果掩码还会让连续分片的最忙一张卡多干 1.75 倍的活，切成 2P 块首尾配对即可配平。Ulysses 的并行度受注意力头数硬约束，与 Ring 互补。有效长度远短于标称长度、Lost in the Middle、注意力稀释，共同说明支持长上下文与用好长上下文是两件事。

**机制可解释性**把问题从“各个部件为什么这样设计”推进到“训练好的权重里究竟学到了什么算法”。起点是一个否定性发现：神经元是多义的，因为特征以近似正交的方向叠加存储：5 个特征挤进 2 维时相邻余弦是 0.309，靠稀疏性与 ReLU 阈值才压得住干扰。稀疏自编码器把这些方向解开成可命名的单义特征，好坏由 L0、解释方差、下游损失恢复率与死特征比例四项指标判定。QK/OV 电路与归纳头给出了上下文学习的机制候选。转码器与归因图把分析从“有哪些特征”推进到“特征之间如何计算”，并用误差节点标出没解释掉的部分。迄今没有任何一个大型 LLM 被完整地、电路级地解释清楚。

**展望**一节把这些线索连起来。幻觉已经有了统计下界（单例率）与电路证据（默认拒答回路的误触发）两条解释；权重记忆的容量约为 2 比特每参数。规模定律的算力项指数只有 0.05，算力翻十倍该项只降 10.9%，这正是推理时扩展受关注的算术背景。

Transformer 的核心设计原则——注意力机制的全局连接、残差连接的梯度保障、并行计算的效率——依然是深度学习最成功的架构范式。回望全书：前面各章回答的是 Transformer 的各个部件为什么这样设计，本章记录的则是这些部件正在被改写的地方。两者合起来要交到读者手里的，是判断下一次架构取舍的依据，而不是某一代模型的参数表。

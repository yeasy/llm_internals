# 第十四章：架构创新与未来趋势

本章所有内容围绕一把尺子：一个新方案省掉的是哪一笔账，代价记在哪一栏，在什么长度、什么批量、什么任务上这笔交易不再划算。前沿路线做的多是同一种交易：把随规模增长的账（随长度平方增长的计算、随长度线性增长的 KV 缓存、每个词元激活全部参数、全部压在训练期的算力）换成固定的或更便宜的账，代价记在精确检索、显存、通信或可验证性上，精确性留在少数几层或少数几步里。本章依次用这把尺子量高效注意力、混合专家、状态空间与混合架构、多模态、Agent 与工具调用、推理时计算扩展、长上下文与机制可解释性，最后在展望里分清哪些判断已有机制解释、哪些只是经验规律、哪些仍未决、哪些是作者的判断。模型版本、基准分数与上下文窗口属于易变事实，做选型时以[附录 A.5](../appendix/a5_volatile_facts.md) 的核验表与官方页面为准。

本章要回答的问题是：把 softmax 换成一块固定大小的状态，能省掉什么、又会丢掉什么（[14.1 节](14.1_efficient_attention.md)）？模型凭什么不必用上全部参数（[14.2 节](14.2_moe.md)）？线性递推的状态空间模型与注意力按什么比例混合才划算（[14.3 节](14.3_ssm_hybrid.md)）？输入不再只是文本词元，图像该怎么变成词元（[14.4 节](14.4_multimodal.md)）？模型如何从“说”走到“做”（[14.5 节](14.5_agent_tool_use.md)）？“推理”这一步能做多厚（[14.6 节](14.6_test_time_scaling.md)）？有长上下文与用好长上下文差在哪（[14.7 节](14.7_long_context.md)）？不听模型自述，怎么读出它学到的算法（[14.8 节](14.8_interpretability.md)）？这些线索合起来，哪些问题已经收口、哪些还敞着（[14.9 节](14.9_outlook.md)）？

九节可以分成四组来读。14.1 至 14.3 节改的是模型内部的算子：注意力、前馈层、序列层。14.4 节改的是输入。14.5 至 14.7 节改的是模型的用法：调用工具、多想几步、读更长的上下文。14.8 节转向模型内部学到了什么，14.9 节收束成展望。各节的算例大量沿用 [3.8 节](../03_components/3.8_gpt_inference_flow.md)的 Llama 3 配置与 FLOPs 口径，生疏时先回看该节。

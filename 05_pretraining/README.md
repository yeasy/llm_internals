# 第五章：预训练：为什么“预测下一个词”能学到知识

预训练（Pre-training）是现代大语言模型的基石。一个看似简单的任务——“预测下一个词”——为什么能让模型学会语法、语义、推理乃至世界知识？三种预训练范式（自回归、掩码语言模型、编码器-解码器）的本质区别又在哪里？

第一部分交付的是一个 Transformer 的形状，权重从哪来留给了本章。本章先把三种范式各自写成可优化的目标函数，并把一条序列算成一个损失标量；再回答语料该有多大、参数与数据怎么配；最后拆开这份语料的来历，看它从原始网页变成一份配比的过程中，抽取、过滤、去重各扔掉多少。沿着五个问题展开：

- [5.1 节](5.1_autoregressive.md)：“预测下一个词”怎样写成一个可优化的目标，一条序列的损失如何逐格算出？
- [5.2 节](5.2_masked_lm.md)：完形填空换来了双向上下文，代价为什么落在信号密度上？
- [5.3 节](5.3_encoder_decoder.md)：编码器双向读、解码器自回归写，两种范式并成一格之后，为什么仍是仅解码器胜出？
- [5.4 节](5.4_data_scaling.md)：给定算力，参数量与数据量该如何分配，工业界为什么普遍不按计算最优来训？
- [5.5 节](5.5_data_pipeline.md)：这些词元怎样从原始网页一步步筛成一份可训练的数据，各步的淘汰率有多高？

# 第五章：预训练：为什么“预测下一个词”能学到知识

预训练（Pre-training）是现代大语言模型的基石。“预测下一个词”这个看似简单的任务，为什么能让模型学会语法、事实与推理？

本章的主线是一句话：预训练是在给定算力下把一份语料的交叉熵压到最低。目标函数决定压的是什么，自回归、掩码语言模型、编码器-解码器的差别都落在“哪些位置产生损失、能看见哪些上下文”上；规模定律决定算力怎样在参数与数据之间分配；数据管线决定这份语料的成色。要把所有上下文上的损失一起压低，模型只能去建模产生文本的过程，知识是这样学到的；目标奖励的是像语料而不是为真，边界也由此划定。今天的默认是仅解码器配自回归目标，按部署量决定训练多久，语料经过过滤、模型打分与去重。

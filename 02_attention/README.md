# 第二章：注意力机制：为什么它是核心

注意力机制是 Transformer 架构的核心。理解它的每一个设计细节，是掌握 Transformer 的基础。

上一章介绍了注意力机制的诞生背景，本章深入其内部运作原理，在给出数学公式的同时，着重解释每一个设计选择背后的直觉与动机。各节依次回答以下问题：

- [2.1 节](2.1_qkv_intuition.md)：查询-键-值的三元组为什么这样设计？不做投影会出什么问题，三套投影各占多少参数？
- [2.2 节](2.2_scaled_dot_product.md)：缩放因子 $\sqrt{d_k}$ 解决了什么数学问题，它的作用范围到哪里为止？
- [2.3 节](2.3_multi_head.md)：多头注意力为什么比单头更强大？头数与每头宽度怎么定，Q 头与 K/V 头为什么可以不一样多（GQA、MQA）？
- [2.4 节](2.4_self_cross_causal.md)：因果掩码为什么是生成任务的必需品，它怎样同时换来并行训练与 KV 缓存？填充、打包与其他掩码各遮哪些格子？
- [2.5 节](2.5_complexity_limits.md)：注意力的 $O(n^2)$ 复杂度意味着什么、又如何应对？训练与推理的账各卡在哪里，复杂度之外还有哪些固有局限？

记号上有一处切换：第一章的 RNN 与早期注意力公式沿用各篇原论文的列向量写法，本章起统一用行向量，每个位置是矩阵的一行，乘在权重左边（见 [2.1.1 节](2.1_qkv_intuition.md)）。计算量按 [1.4.5 节](../01_introduction/1.4_transformer_idea.md)的约定计数，一次乘加记 2 次浮点运算。

# 第二章：注意力机制：为什么它是核心

注意力是一次可导的软查表：每个位置拿查询与所有键打分，按分数混合各位置的值。本章依次回答这张表查什么、分数的尺度由什么定、为什么要分成多份查、谁能被查到、查一次要花多少，每一节放开上一节的一个默认条件。

- [2.1 节](2.1_qkv_intuition.md)：三套投影各有硬理由。不投影时分数矩阵必然对称，而且每个位置给自己的分最高；被学到的是 $W^Q (W^K)^\top$ 与 $W^V W^O$ 两个乘积。
- [2.2 节](2.2_scaled_dot_product.md)：除以 $\sqrt{d_k}$ 让分数尺度与头宽无关，只管到初始化。Softmax 的权重比只看分数差，候选一多同样的优势会被稀释。
- [2.3 节](2.3_multi_head.md)：多头把一个加权平均换成 $n_h$ 个，参数与运算量不变；每头宽度定在 64 到 128，推理时几个 Q 头共用一套 K/V（GQA）。
- [2.4 节](2.4_self_cross_causal.md)：K、V 取自哪条序列、哪些格子可见是两个独立的旋钮。因果掩码让训练一次得到 $n$ 个监督信号，也让旧位置的 K、V 可以缓存。
- [2.5 节](2.5_complexity_limits.md)：平方项要到 $n \approx 12d$ 才追平线性项；训练先撞上分数矩阵的显存，Decode 受显存带宽与 KV 容量约束；复杂度之外还有四条换硬件也去不掉的性质。

本章起统一用行向量记号（见 [2.1.1 节](2.1_qkv_intuition.md)），计算量按 [1.4.5 节](../01_introduction/1.4_transformer_idea.md)的约定计数。
